# 🏢 Allocato – Smart Resource Allocation System

Allocato is a full-stack **Smart Hall & Resource Booking System** designed to manage hall/resource reservations efficiently. It prevents double booking, handles time-slot conflicts, and displays live bookings with a clean, full-screen responsive UI.

## 🚀 Key Features
- 👤 User-based booking using name input
- 🏢 Multiple hall/resource selection
- ⏰ Time-slot based booking system
- ❌ Automatic conflict prevention (no double booking)
- 📋 Live display of current bookings
- 🗑️ Delete booking functionality
- 🎨 Modern, professional, full-screen responsive UI
